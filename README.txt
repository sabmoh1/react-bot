Telegram Auto Reaction Bot
==========================

1) ثبّت Python 3.10 أو أحدث.

2) افتح Terminal داخل هذا المجلد وشغّل:
   py -m pip install -r requirements.txt

3) افتح Tokens.txt.

4) ضع كل Bot Token تحت الإيموجي المطلوب، مثل:

   [❤]
   TOKEN_1
   TOKEN_2

   [🔥]
   TOKEN_3

5) في rect.py غيّر:
   CHANNEL = "@react_tes"

   إلى القناة المطلوبة.

6) شغّل:
   py rect.py

مهم:
- التوكنات لا تُخزن داخل rect.py.
- لا يوجد HTML مطلوب لقراءة التوكنات.
- البرنامج يقرأ Tokens.txt عند كل تشغيل.
- كل Bot Token يرسل Emoji واحدًا.
- يمكن وضع عدة Bots لنفس Emoji.
- الأقسام الفارغة يتم تخطيها.
- Token غير صالح لا يوقف باقي البرنامج.
- البرنامج يستخدم Bot واحدًا فقط كـ Listener؛ باقي Bots لا تعمل polling،
  وهذا يمنع سيل getUpdates / HTTP 200 في الطرفية.
- يجب أن تكون الـ Bots مضافة إلى القناة ولديها الصلاحيات اللازمة للتفاعل.
- Telegram قد يرفض Emoji معينًا إذا كانت تفاعلات القناة لا تسمح به؛
  البرنامج يسجل الفشل ويكمل باقي التفاعلات.

أمان:
إذا كانت توكنات حقيقية قد ظهرت سابقًا في Terminal أو GitHub أو أي مكان عام،
قم بإلغائها/تدويرها من BotFather ثم ضع التوكنات الجديدة في Tokens.txt.
